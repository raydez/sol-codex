# Real-world SoL-Codex Results

No real Codex token-saving result is published in this repository yet.

This file is intentionally empty of performance claims until a real Codex CLI/Desktop experiment satisfies the validation protocol in `docs/validation-protocol.md`.

## Required evidence for a result entry

Every published entry must include:

- date;
- exact Codex version;
- exact SoL-Codex version;
- authentication/billing mode where relevant;
- exact model;
- exact reasoning effort;
- benchmark/task-set identifier;
- exact repository revisions;
- number of distinct tasks and repeats;
- success and deterministic test-pass rates;
- total tokens and tokens/success;
- paired token-saving estimate and 95% CI;
- quality non-inferiority CI results;
- validation status;
- link/path to immutable `report.json` and manifest.

Synthetic or fake-Codex test fixtures must never be entered here as performance evidence.
